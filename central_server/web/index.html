Crisis Threat Level Postures

Select the system-wide threat status condition. Modifies scheduling and controller access validation policies.

🟢

Condition Green

NORMAL POSTURE

Standard operation. All timezone intervals, schedules, reader policies, and card permissions operate normally.

🟡

Condition Amber

HIGH SECURITY

Access Restricted. Timezone schedules suspended. Standard staff badges blocked. Only Super Admins allowed entry.

🔴

Condition Red

FULL LOCKDOWN

Complete Isolation. All portals locked shut. All card swipes rejected. Force Lock commands dispatched to controllers.
